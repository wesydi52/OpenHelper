# Джарвис (без облачного ИИ)

Личный помощник на Python. **Не использует Claude или другие ИИ-сервисы**: команды разбираются
правилами, русские даты — собственным офлайн-парсером. Работает голосом на ПК и через Telegram.

## Запуск
```bash
pip install -r requirements-jarvis.txt
python -m jarvis                      # консоль
python -m jarvis --voice              # микрофон: «Джарвис, запомни ...»
python -m jarvis --voice --telegram   # голос на ПК + Telegram-бот
python -m jarvis --telegram --headless  # только бот и напоминания (сервер/автозапуск)
```
Голос: `pip install SpeechRecognition pyaudio pyttsx3`.
- По умолчанию распознавание через Google Web Speech (нужен интернет).
- **Полностью офлайн:** `pip install vosk`, скачайте `vosk-model-small-ru` с alphacephei.com/vosk/models,
  распакуйте и укажите путь: `JARVIS_VOSK_MODEL=/путь/к/vosk-model-small-ru-0.22`.
- Озвучка — pyttsx3 (системные голоса; на Windows нужен русский голос, например «Ирина»).

## Примеры команд
| Что сказать | Результат |
|---|---|
| «Джарвис, запомни, что мне надо сдать отчёт до пятницы 18:00» | задача + оповещения за сутки, за час и в срок |
| «запомни, что нужно купить подарок до 25 ноября» | срок без времени = 18:00; оповещения за сутки и в 9:00 в день срока |
| «напомни через час позвонить маме» / «напомни завтра в 9 утра …» | разовое напоминание |
| «напомни полить цветы» | Джарвис спросит «Когда напомнить?» |
| «что у меня на сегодня» / «какие у меня дела» | список с номерами |
| «готово два» / «удали хлеб» | отметить / удалить по номеру или слову |
| «запомни, что пароль от вайфая 1234», «покажи заметки» | заметки (если нет срока и слов «надо/нужно») |
| «погода», «погода в Казани», «новости», «который час», «проверь почту» | справки |
| «открой калькулятор», «открой ютуб», «громкость 40», «найди …» | управление ПК (только локально) |

Понимает: «через 2 часа», «через полчаса», «завтра», «послезавтра», «в пятницу», «25 ноября»,
«двадцать пятого ноября», «до 5 числа», «в 18:30», «в шесть вечера», «к пяти часам»,
«утром/вечером». Час 1–7 без «утра/вечера» и без даты считается дневным («в 6» = 18:00);
с явной датой или двоеточием («завтра в 6», «в 7:30») время берётся буквально.

## «Не понял», уточнения и журнал
- Непонятную фразу Джарвис переспрашивает **два раза** («Прошу прощения, сэр, я не расслышал…»), потом сдаётся и
  записывает фразу в журнал (только текст, без аудио). Обращение — `JARVIS_ADDRESS` (по умолчанию «сэр»).
- Не хватает данных — открытый вопрос («Когда напомнить, сэр?», «Какого числа, сэр?»); «в выходные» —
  с вариантами («В субботу или в воскресенье, сэр, и во сколько?»). Вопрос действует 2 минуты, «отмена» снимает его.
- Раз в день после `JARVIS_REVIEW_TIME` (по умолчанию 20:00) Джарвис сам говорит, сколько накопилось непонятных
  фраз; полный список уходит в Telegram. Также: «покажи непонятные фразы», «очисти журнал непонятных фраз».
- Новые выражения времени: «в обед» (13:00), «после обеда» (15:00), «под вечер» (17:00), «через пару часов» (2,5 ч),
  «через минутку», «в начале месяца» (1 число), «на следующей неделе в среду».

## Напоминания
Фоновый планировщик каждые 10 секунд проверяет дела. Оповещение приходит **везде, где Джарвис запущен**:
печатается в консоли, **произносится голосом** (если `--voice`) и **отправляется в Telegram** (если `--telegram`).
Если программа была выключена в нужное время, при следующем запуске придёт одно «Пропущенное напоминание».
Данные: `~/.jarvis/data.json`. Если Джарвис не запущен — оповещений нет (это локальное приложение).

## Telegram
1. Создайте бота у @BotFather, `export JARVIS_TG_TOKEN=...`.
2. Запустите с `--telegram`: в консоли появится `/start КОД`. Отправьте боту это сообщение — чат привяжется
   (или задайте `JARVIS_TG_OWNER=<chat_id>`). Остальным бот отвечает «Доступ запрещён».
3. В боте работают те же текстовые команды. Управление ПК из Telegram выключено; включить: `JARVIS_TG_ALLOW_PC=1`.

## Настройки
`JARVIS_CITY`, `JARVIS_USER`, `JARVIS_WAKE_WORDS` (через запятую), `JARVIS_LANG`, `JARVIS_VOSK_MODEL`,
`JARVIS_TG_TOKEN`, `JARVIS_TG_OWNER`, `JARVIS_TG_ALLOW_PC`, `JARVIS_MAIL_USER/PASSWORD/IMAP_HOST`,
`JARVIS_NEWS_FEEDS`, `JARVIS_HOME`.
