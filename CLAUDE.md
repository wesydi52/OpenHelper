# OpenHelper / Джарвис — инструкция для Claude Code

Личный голосовой помощник «Джарвис» на Python для **Windows**. Владелец говорит по-русски, живёт в Варшаве.
**Требования лежат в `JARVIS_PLAN.md` — прочитай его целиком перед любой работой.** Текущая реализация описана
в `JARVIS.md`, код — в `jarvis/`, тесты — в `tests/` (`python -m pytest tests`, сейчас 394 проходят; фейки ПК/Spotify/сервисов — `tests/fakes.py`).
Каталог `stockbot/` к Джарвису не относится, не трогай.

## Жёсткие правила
1. **Никаких облачных ИИ-сервисов** (Claude, Gemini и т.п.). Команды разбираются правилами, даты — своим
   парсером `jarvis/ruparse.py`. «Краткий ответ» = открыть Google с запросом в браузере, без API.
2. **Секреты не в репозиторий:** токены (Telegram, Twitch, Spotify), Dota ID, список важных отправителей,
   кодовая фраза — только переменные окружения или локальный конфиг вне git. Не логировать кодовую фразу и аудио.
3. **Опасные действия** (выключение, перезапуск, сон, закрытие программ, отправка чего-либо наружу) — только с
   подтверждением «да»; выключение/сон/перезапуск — «да» + отсчёт 15 с, можно сказать «отмена». Из Telegram
   управление ПК выключено по умолчанию.
4. **Пароли в заметках** — хранить зашифрованными, ключ — голосовая кодовая фраза (слабее мастер-пароля: сказать
   владельцу). Буфер обмена и пароли не озвучивать без подтверждения.
5. **Стиль общения Джарвиса:** официальный, обращение «сэр». Непонятную фразу — переспросить, максимум два раза,
   затем извиниться, записать фразу в журнал и предложить написать в Telegram. Не хватает данных → открытый
   вопрос; выбор из двух режимов (сухая/влажная уборка) → вопрос с вариантами. Не додумывать молча.
6. **Если требование в плане помечено ОТКРЫТО или противоречит коду — спроси владельца**, а не угадывай.
   Спрашивай по одному вопросу, с вариантами ответа, коротко.
7. **Честность о проверке.** Среда разработки — Linux без микрофона, звука и Windows. Всё, что нельзя запустить
   здесь (голос, Windows-команды, Telegram, Spotify, Twitch, Dreame), помечай «не проверено вживую» и пиши
   тесты с подставными зависимостями. Не заявляй, что работает, пока не проверено.

## Как работать
- Двигайся по порядку из раздела 9 плана, **один пункт за раз**: сначала тесты на фразы владельца, потом код.
- Фразы владельца из плана (раздел 3 и др.) — готовые тестовые примеры; держи их в `tests/`.
- Мелкие коммиты в ветку `claude/beautiful-johnson-4qyju0`; PR без просьбы не создавать.
- Обнови раздел «Разрыв» в `JARVIS_PLAN.md`, когда закрываешь пункт, и `JARVIS.md` — когда меняется запуск.
- Известные ошибки конфигурации: в `jarvis/config.py` по умолчанию «Москва» и российские новости — заменить на
  Варшаву (`Europe/Warsaw`), польские и украинские ленты (русские — по запросу), озвучка на языке источника.
